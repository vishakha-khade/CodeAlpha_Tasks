# CodeAlpha Tasks

This repository contains three projects developed as part of my CodeAlpha internship tasks using HTML, CSS, and JavaScript.

## Projects

### 1. Calculator
A personal portfolio website showcasing projects, certifications, resume, and contact information with a responsive layout and theme toggle.

* **Technologies:** HTML5, CSS3, JavaScript
* **Live Demo:** [View Portfolio](https://codealphaporfolio.vercel.app/)
* **Source Code:** `CodeAlpha_Portfolio/`

### 2. Image Gallery

A responsive image gallery that allows users to view and navigate images through an interactive interface.

* **Technologies:** HTML5, CSS3, JavaScript
* **Live Demo:** [View Image Gallery](https://codealphaimagegallery-pearl.vercel.app/)
* **Source Code:** `CodeAlpha_ImageGallery/`

### 3. Portfolio Website
A simple and interactive calculator that performs basic arithmetic operations with a clean and user-friendly interface.

* **Technologies:** HTML5, CSS3, JavaScript
* **Live Demo:** [View Calculator](https://codealphacalculator-pi.vercel.app/)
* **Source Code:** `CodeAlpha_Calculator/`
